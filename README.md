## 🚀 Key Features

* **⚡ Instant Native Speed**: Zero Electron, zero WebView2 bloat. Launches in under 0.3s with instant folder navigation.
* **👁️ Spacebar QuickLook**: Instant macOS-style file previews for images, PDFs, code, audio, video, and text without opening default apps.
* **🪟 Dual-Pane Split View (F10)**: Side-by-side independent directory browsing with synchronized keyboard transfers.
* **🔓 File Lock Detector & Unlocker**: Identifies and clears background processes locking files from rename or deletion (no more *"File in use"* errors).
* **📑 Advanced Multi-Tabs**: Open, close, duplicate, and restore recently closed tabs with history tracking.
* **📝 Contextual File Notes**: Attach persistent rich notes directly to any file or folder (stored in an isolated offline SQLite database without altering your files).
* **🔒 AES-256 Encrypted Vault**: Hardware-accelerated client-side locker with PBKDF2 password derivation for private documents.
* **🧹 Self-Cleaning Staging Folder**: Automatically purges temporary downloads after 24 hours or 7 days to eliminate drive clutter.
* **📄 Offline Document Converter**: 1-click batch conversion for Word, Excel, and images to PDF without uploading data to external cloud services.
* **🖼️ Batch Image Resizer**: Quick dimension adjustment and scaling directly from the toolbar.
* **📊 Disk Storage Analyzer**: Built-in treemap space visualizer to locate space hogs.
* **🛡️ 100% Offline & Private**: Zero telemetry, zero analytics, zero external network connections.
